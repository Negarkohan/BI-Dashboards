# Toman Bike Shop – Power BI Dashboard

An interactive Power BI dashboard built for analyzing the performance of a bike rental shop.  
This dashboard provides insights into revenue, profit trends, rider demographics, and seasonal performance — designed for decision-making and business reporting.

---

## 🚴 Key Features

- Year filter (2021 / 2022)
- Monthly trend of riders & profit
- Total revenue and profit KPIs
- Seasonal revenue comparison
- Rider demographic donut chart
- Clean, minimal, business-friendly UI

---

## 📥 How to Use

1. Clone or download this repository  
2. Open the `Dashboard.pbix` file in **Power BI Desktop**  
3. Use the year filter to navigate insights (2021 / 2022)
